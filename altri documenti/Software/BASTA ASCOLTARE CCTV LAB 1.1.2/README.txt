========================================================================
  BASTA ASCOLTARE - CCTV VIDEO LAB
========================================================================

Benvenuto in Basta Ascoltare - CCTV Video Lab!
Questo programma è un'applicazione standalone (portatile): non richiede 
alcuna installazione per essere utilizzato.


1. COME AVVIARE IL PROGRAMMA
------------------------------------------------------------------------
- Fai doppio clic su "Basta_Ascoltare_CCTV_Lab.exe" per avviare subito 
  l'applicazione.
- Puoi spostare il file .exe in qualsiasi cartella del tuo PC o crearne 
  un collegamento sul Desktop.


2. REQUISITI DI SISTEMA
------------------------------------------------------------------------
- Sistema Operativo: Windows 10 o Windows 11 (64-bit).
- Componente richiesto: Microsoft Edge WebView2 Runtime.

Nota: Su Windows 11 questo componente è già preinstallato di serie. 
Se utilizzi Windows 10 e il programma non si avvia, scarica e installa 
gratuitamente "Microsoft Edge WebView2 Runtime" dal sito ufficiale Microsoft.


3. RISOLUZIONE PROBLEMI (AVVISO WINDOWS SMARTSCREEN)
------------------------------------------------------------------------
Al primo avvio, Windows Defender SmartScreen potrebbe mostrare una finestra 
blu con l'avviso "PC protetto da Windows" (poiché l'applicazione non ha 
una firma digitale commerciale).

Per avviare regolarmente il programma:
1. Clicca sulla scritta "Ulteriori informazioni" nella finestra di avviso.
2. Clicca sul pulsante "Esegui comunque" che apparirà in basso.

Questa operazione è richiesta soltanto al primo avvio.
